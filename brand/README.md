# xats brand kit

Official artwork for **xats / Cross-Agent Teams**.

The mark is an abstract X made from four interlocking blue and mint routing
ribbons. It represents different coding agents exchanging messages as peers.

## Choose an asset

- `xats-mark.svg`: primary transparent vector icon. Use for small UI marks.
- `xats-wordmark-dark.svg`: icon and outlined xats lettering for dark surfaces.
- `xats-wordmark-light.svg`: icon and outlined xats lettering for light surfaces.
- `xats-stacked-dark.svg` / `xats-stacked-light.svg`: stacked signatures.
- `xats-app-icon.svg`: dark rounded-square avatar, favicon, or app icon.
- `xats-mark-mono-dark.svg` / `xats-mark-mono-light.svg`: single-color versions.
- `xats-mark-{size}.png`: transparent icons from 16 to 2048 pixels.
- `xats-app-icon-{size}.png`: avatars and app icons, including 180px for Apple.
- `xats-social-card.png`: 1200 x 630 sharing card.
- `xats-brand-preview.png`: overview, not a replacement for the individual files.

All SVG lettering is outlined. No external fonts are required to render the
artwork. Wordmark outlines use DejaVu Sans Mono Bold.

## Palette

| Color | Hex |
| --- | --- |
| Route blue | `#7fb4ff` |
| Route mint | `#7ad3a4` |
| Dark background | `#0b0d10` |
| Light lettering | `#f3f5f8` |

## Usage

Keep the mark's proportions and the gaps between the routes. Leave clear space
around the mark. Use the light-surface wordmark on light backgrounds and the
dark-surface wordmark on dark backgrounds. Use a monochrome asset when color is
not available. Do not add shadows, stretch the mark, or recolor individual routes.

The brand kit does not change package names: installation remains
`npx xats-setup`. The full project name remains **Cross-Agent Teams**.

The initial concept was generated with Seedream Pro and then refined into clean,
flat vector geometry and production exports. No trademark registration or
trademark-clearance claim is implied.
